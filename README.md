# Dra. Karen Rugani — site

Landing page de uma página (HTML, CSS e JS puros, sem build) da Dra. Karen Rugani, harmonização facial e corporal em Belo Horizonte.

- `index.html` — conteúdo, SEO, Open Graph e Schema.org
- `css/styles.css` — estilos (mobile-first)
- `js/main.js` — menu, carrosséis, cookies (LGPD) e mapa sob consentimento
- `img/` — fotos em WebP

Para ver localmente: `python -m http.server 5173` e abra http://localhost:5173.

Antes de publicar, preencha os campos marcados com `[PREENCHER]` e troque `SEUDOMINIO` pelo domínio real.
